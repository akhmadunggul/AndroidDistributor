### 1. The Production-Grade Claude Prompt
This prompt is explicitly optimized for advanced large language models. It steers clear of basic definitions and instructs the AI to generate actual, production-ready Kotlin source code. It includes details for:
* **Relational Schema Design:** Maps out definitions for Product, Reseller, Stock Ledger, Transaction, Transaction Detail, and Payment Log tables using strict Room annotations.
* **SQL Ledger Math:** Directs the model to write aggregate SQL queries that dynamically calculate real-time inventory from append-only inputs/outputs instead of hardcoding a volatile stock number.
* **FIFO Payment Allocation Engine:** Requests the explicit algorithmic code required to intake a flat payment amount from a reseller and cleanly split it across the oldest unpaid invoices first.
* **System Utilities:** Mandates structural definitions for Android's `PdfDocument` graphics canvas and `FileProvider` logic to assemble shareable receipts that bypass external servers entirely.
